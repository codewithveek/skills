# The starter kit

`assets/starter/` is a working Remotion project with an example video (16:9, a 9:16 cutdown and a
thumbnail). Copy it, `npm install`, and replace the example.

## 2. A video

1. `timeline.ts`: `{ id, title, crossfade: 12, scenes: [{ id, frames, cues }] }`. `frames` is the base
   length; narration may lengthen it. `cues` are fallback captions for videos without a voice. The file
   must import nothing (the caption script reads it with plain Node).
2. `narration.ts`: `{ [sceneId]: [{ at, text, say? }] }`.
3. `scenes.tsx`: export each scene component and a `SCENES` map from scene id to component.
4. `Root.tsx`: add `[VIDEO, SCENES, VOICE, music?, levels?]` to `VIDEOS`; add the id to `VERTICAL` for
   a 9:16 cutdown; add a `THUMBNAILS` entry.
5. `npm run voice`, then check stills, then `./render-all.sh <Title>`.

Scene components are also registered alone as `<videoId>-<sceneId>` for stills and previews.

## 3. The app window, camera and pointer

```tsx
<Step
  eyebrow="Step 2 · Payout policy"
  text="Decide when commissions become payable."
  camera={[
    { f: 24, s: 1 },                                 // wide
    { f: 48, at: "sec-policy", s: 1.36 },            // zoom to the section
    { f: 142, at: "policy-footer", fy: -1.5, s: 1.45 },  // aim a little above the footer
  ]}
  pointer={[
    { f: 22, x: 1000, y: 760 },                      // enter from a raw point
    { f: 44, at: "in-hold", fx: 0.4, click: true },  // click 40% across the field
    { f: 112, at: "btn-save", click: true },
  ]}
>
  <AppFrame …>…</AppFrame>
</Step>
```

- Camera keys: `f` frame, `s` zoom, and an aim (`at` an anchor, or `x`/`y` a screen point), with
  `fx`/`fy` (fraction of the anchor's box; can go outside 0–1) and `dx`/`dy` (pixels). Moves between
  keys ease in and out.
- The camera clamps so it never shows past the screen's edges, and frames only the part of the window
  visible in the frame (the window may run off the bottom).
- Pointer keys use the same aims; `click: true` dips the cursor, draws a ring and plays the click.
  `pointerShow={[from, to]}` fades it in and out.
- `AppWindow` without `Step` gives a window with no headline (for custom layouts, two windows in one
  scene, thumbnails). `enter`/`exit` animate it in and out.

## 4. Anchors

Wrap any element the camera or pointer must reach: `<Anchor name="btn-save" inline><Btn>Save</Btn></Anchor>`.
Anchors measure their box in screen coordinates on every frame, so they follow layout changes,
scrolling and rows sliding in. Name them by role (`in-email`, `sec-invite`, `row:Ken Mwangi`). A
missing anchor makes the camera and pointer fall back to the screen centre; if something aims at the
middle of nowhere, check the name.

## 5. Rebuilding a screen

- Start from the reference screenshot at 1440 wide; match the page padding, card radius, font sizes
  and spacing. Use the kit's controls and the product's tokens; add components for anything special.
- Build the product's real app frame (sidebar items and their icons, top bar, active state).
  `AppFrame` is a generic stand-in.
- Scroll long pages with the frame's `scroll` prop (animate it); anchors follow.
- State changes are plain conditions on the frame: `frame >= SAVE + 4 ? "Saved." : ""`, a row that
  pops in with `pop()`, a value that types with `typed()`.
- Keep scene timings as named constants at the top of the scene (`const SAVE = 112`) and key the
  camera, pointer and state off them.

## 6. Reusing scenes

A launch video can reuse tutorial scenes with its own headline:

```tsx
<StepCopy.Provider value={{ eyebrow: "Pay", text: "Settled in each affiliate's own currency." }}>
  <Detail />
</StepCopy.Provider>
```

Extract the screen part of a scene into its own component (`OverviewScreen`) when another layout
needs it (a thumbnail, a two-window scene).

## 7. Kinetic text timed to the voice

```tsx
import VOICE from "./voice.json";
const line = lineAt(VOICE, "problem", 1);     // { from, frames }
<Words text="Paying affiliates across borders isn't." at={line.from - 2} size={74} />
```

Reveal parts of a sentence at fractions of the line (`line.from + 0.26 * line.frames`) to land them as
they're said. Read timings from `voice.json`, never hard-code them; they change when wording does.

## 8. Vertical and square

Register `<Title>Vertical` (1080x1920) by adding the video id to `VERTICAL`. The same scenes adapt:
headlines get bigger and wrap; the window becomes a taller 4:5 panel; the camera zooms at least 2× so
it frames a readable column of the UI; captions are burned in. Check stills of every product moment
in vertical: aims that worked wide may need an `fx` nudge to keep the action in the column. For
square, register a 1080x1080 composition the same way.

## 9. Thumbnails

`THUMBNAILS` entries render `Thumbnail`: brand and a two-line title on the left, one of the video's
scenes on the right, held at a chosen frame (pick a resolved, telling moment: a chart fully drawn, a
"Settled" badge, a highlighted price). `render-all.sh` renders 1920 PNG and 1280 JPG versions and
embeds the JPG as the MP4's cover art. Each 16:9 video with a thumbnail also **opens on it**
(`withPoster`: 25 frames held, a 10-frame fade into the video, 15 frames added to the length), because
feeds such as X preview the opening frame and ignore cover art. Captions are shifted to match;
vertical cutdowns start straight on their hook. Turn it off with `OPEN_ON_THUMBNAIL = false`.
Thumbnails are 240-frame compositions rendered at frame 239, not `<Still>`s with `<Freeze>`: a
frozen frame past a still's one-frame duration renders nothing.

## 10. Commands

| Command | Does |
|---|---|
| `npm run studio` | Preview with a timeline scrubber; edits reload live |
| `npm run voice` | Narration → clips + `voice.json` (cached per line) |
| `npm run music` | `bed.wav` and `upbeat.wav` (`MUSIC_SECONDS`, default 90) |
| `./stills.sh comp:f1,f2 …` | Half-size PNGs of single frames into `stills/` |
| `./render-all.sh [Comp …]` | Render, normalise to -16 LUFS, thumbnails as cover, captions |
| `npm run vtt` | Captions only |
| `node scripts/audio-report.mjs file` | Levels, spectrum, loudness timeline |
| `npx tsc` | Typecheck |
